Variant C

Journey tabs

The page is split into three jobs so they don't compete: Now for glancing and acting, Journey for looking back, and Settings for configuring. Each tab stays small and focused, and the page can grow (goals, notes, stats) without getting longer.

Information architecture

  1. Header and tabs"Since" + title, left-aligned in an editorial style. The segmented control sticks to the top while you scroll.
  2. NowA progress ring to the next milestone, with the theme pattern inside and the counter centered. Unit switch, "until next milestone" line, a three-stat strip, hold-to-reset, and a share card.
  3. JourneyHistory told as chapters. Each streak is a chapter with the milestones it reached and the note from the reset that ended it. The current chapter shows the upcoming milestone.
  4. SettingsTheme swatches (and custom photo), widget unit, reminders, name and start date. Delete sits alone at the end.

Trade-offs

Why pick it

  • Clearest separation of jobs, and the one that scales best
  • History reads as a story of progress, not a list of failures
  • Hold-to-reset guards the one destructive-feeling action
  • Settings don't crowd the motivating view

Watch out for

  • Tabs hide content, so History and Settings are one tap further away
  • Tabs inside a sheet add navigation depth
  • Hold-to-reset needs clear teaching the first time

Try: press and hold the Reset button, then open Journey to see the new chapter. Theme swatches in Settings stay in sync with the top bar.
