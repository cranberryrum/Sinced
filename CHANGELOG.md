# Changelog

All notable changes to the Since app will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-10-31

### Added
- Initial release of Since app
- Event tracking with custom emojis and names
- Real-time elapsed time display
- Home Screen widget (1×1 systemSmall)
- Event creation flow with emoji picker
- Event detail view with comprehensive timer
- Reset functionality with optional notes
- Event history timeline
- Swipe actions (delete, archive, edit)
- Share progress feature
- Milestone tracking (24h, 7d, 30d, 90d, 365d)
- Onboarding experience
- Dark mode support
- Accessibility features (VoiceOver, Dynamic Type)
- Haptic feedback throughout the app
- AppGroup-based storage for widget sync
- Intelligent widget refresh strategy

### Design
- Minimal, Apple-native interface
- SF Pro typography
- System colors with dark mode support
- Rounded corners and soft shadows
- Calm, encouraging copy

### Technical
- SwiftUI-based architecture
- WidgetKit integration
- MVVM pattern (Model-View-ViewModel)
- JSON-based local storage
- AppGroup shared container for widget data
- Timer-based UI updates
- Codable data models
